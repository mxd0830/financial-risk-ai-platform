## 评测核心结论

| 指标 | 值 |
|---|---:|
| AUC | 0.7691 |
| KS | 0.4012 |
| PR-AUC | 0.2565 |
| Brier | 0.0672 |
| **ECE** | **0.0034**（校准优秀） |

**风险分层（真实违约率严格单调）**：
`<2% → 1.05%`，`2-5% → 3.13%`，`5-10% → 7.25%`，`10-20% → 14.3%`，`>20% → 30.2%`（lift 0.13 → 3.74）。

**业务 tradeoff**：拒绝 PD>20% 的 8.4% 客户可挡住 31.3% 违约；拒绝 PD>10% 的 25.2% 客户可挡住 61.1% 违约。

## 关键问题与解决方案

### 1. 0.5 阈值不适合风控

阈值 0.5 下只预测 0.33% 违约、召回仅 2.3%（太保守）。风控阈值应按业务目标选，统计最优 Youden ≈ 0.066。结论已写入报告。

### 2. 校准曲线极端 bin 的 n=1 假象

等频分箱在最高分位出现 n=1（pred=0.728 actual=1.0），是极端值处的分箱 artifact，不代表校准差——ECE 0.0034 已说明整体校准优秀。
