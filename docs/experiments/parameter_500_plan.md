# 参数控制实验：固定 500 次调用预算

本方案对应用户澄清的研究目标：控制推理参数、观察输出变化，取代 `experiment_redesign.md` 的缺失提示 A/B 方案。本轮不执行该提示优化实验，也不修改旧数据。

## 预算

|参数|取值|任务×条件×重复|调用数|
|---|---|---|---:|
|temperature|0.1 / 0.5 / 0.9|10×3×3|90|
|top_p|0.5 / 0.9 / 1.0|10×3×3|90|
|top_k|10 / 40 / 100|10×3×3|90|
|num_predict|64 / 256 / 512|10×3×3|90|
|num_ctx|4096 / 8192 / 16384|10×3×3|90|
|seed|固定42 / 42、43、44、45|5×2×4|40|
|预热|首次1次、上下文各容量每轮1次|1+3×3|10|
|合计|||500|

500 指总调用次数，包含预热，不是 500 个独立样本。前四组共用 10 个固定任务：字段抽取、缺失字段、规则判高风险、规则判低风险、单位换算、冲突处理、概念解释、风险解释、沟通话术、短故事。前六个有预设 JSON 真值，后四个是自由文本。任务范围有限，结论只用于探索参数效应。

上下文组另外固定 10 个输入：5 短、3 中、2 长，均检索文首/文末校验码；比较相同输入下的正确率、实际提示 token 计数和内存。不同容量按重复轮转顺序，各容量先预热，容量块内随机任务顺序。

除目标变量外，其余参数固定为 temperature=0.5、top_p=0.9、top_k=40、min_p=0、repeat_penalty=1、num_ctx=4096、num_predict=256。前三次重复的 seed 分别为42/43/44，各条件同一次重复使用相同 seed。模型固定为 qwen3:30b，关闭 thinking。完整模型摘要、后端版本、参数和提示哈希保留于实验目录。

## 评价与结论规则

- 内容：严格 JSON 对象率、字段/类型/数值完全正确率；自由文本不以关键词代替语义评分，不声称测得其整体正确率。
- 多样性：同任务同条件的唯一输出数、两两完全一致比例、归一化 Levenshtein 距离。另列自由文本结果，避免稳定的 JSON 输出掩盖措辞变化。
- 输出长度：生成 token 数、done_reason=length 的截断次数、原始响应内容。区分参数上限和实际长度。
- 性能：请求墙钟中位数/P95、纯解码 token/s、提示处理时间、加载时间；记录缓存字段（如果后端提供），不混淆冷启动与解码速度。
- 上下文：按短中长输入分别汇总，不由短问答推断长输入表现；保存实际生效容量和 size_vram。
- seed：逐任务检查固定 seed 的4次是否完全一致，与4个明确种子的变化比较；不保证跨模型或跨后端复现。
- 三次重复不足以作强统计推断。观察到的非单调性、无差异均如实报告，不为参数预设结论。自然停止也不保证语义完整。

## 执行与恢复

单进程并发1，以文件锁防重复启动。每20次或运行块满120秒休息60秒；每次前后读取系统热压力，fair时等待，serious/critical时停止。每条响应立即追加JSONL并fsync；记录失败但不自动无限重试，连续3次错误退出。续跑校验模型digest、后端版本与计划哈希，跳过已记录ID。创建 `experiments/parameter_500/STOP` 可在当前请求完成后停下。

命令：

```sh
.venv/bin/python scripts/run_parameter_500.py prepare
.venv/bin/python scripts/run_parameter_500.py run --max-calls 100
.venv/bin/python scripts/report_parameter_500.py
```

`--max-calls` 限制本次启动的新调用数，重复执行可续跑，总计划不会超过500条。报告生成完全离线。实际进展以 `responses.jsonl` 为准，未完成时不得称为500次完整结果。
