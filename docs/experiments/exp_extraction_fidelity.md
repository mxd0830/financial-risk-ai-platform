# 实验：结构化抽取忠实度（5000 条真实样本基线）

## 1. 业务问题

金融场景需要 LLM 从客户档案里可靠抽取结构化字段。此前实验 A 只用 3 条手写样本，样本相似、量太小。本实验改用 **Home Credit 真实借款人**构造 5000 条多样化评测集，测抽取忠实度基线。

## 2. 数据与构造

- 数据源：Home Credit `application_train.csv`（307,511 真实借款人）
- 构造：剔除关键字段缺失 + 失业占位符（`DAYS_EMPLOYED=365243`）后，随机抽 5000 条；每条 = 「客户档案」自然语言 prompt + 10 字段 ground truth
- 10 字段：`gender / age / education / contract_type / income_total / loan_amount / annuity / goods_price / children / employment_years`
- 生成脚本：`scripts/build_eval_set.py`（生成物 `data/processed/eval_extraction.jsonl`，gitignore、可重生成）
- 评测脚本：`scripts/eval_extraction.py`

## 3. 评价指标

JSON 可解析率、字段完整率、全字段全对率、分字段一致率（数值容差 0.1%，字符串精确匹配）。

## 4. 实际结果（temp=0.1，n=5000）

| 指标 | 结果 |
|---|---:|
| JSON 可解析率 | 100.00% |
| 字段完整率 | 100.00% |
| 全字段全对率 | 100.00% |
| 分字段一致率（10 字段） | 全部 100.00% |

失败样本数：0。

## 5. 诚实结论

- 这是「照着档案抄数字」的**简单任务**，30B 模型在 temp=0.1 下做到 100% **符合预期、不代表模型强**，只说明基线已到天花板。
- 该 n=5000 的数字可作为「理想条件下抽取忠实度」的正式基线引用。
- 真正区分度要靠**加难变体**：温度扰动（temp=0.5）、字段缺失、矛盾值、干扰文本（对应实验 D）。

## 6. 下一步

- temp=0.5 重跑，观察采样是否破坏格式稳定；
- 构造「字段缺失 / 矛盾值 / 干扰文本」变体，测模型是否**编造缺失字段**或忽略冲突。
